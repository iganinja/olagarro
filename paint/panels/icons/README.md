# The tools' icons

The icons of Paint's tool panel, from OUI Paint, built into `olagarro::PaintPanels`:

- `godot/`: the Godot editor's icons, under the MIT license in `godot/LICENSE.txt`. They are drawn for a dark
  interface; `paint/panels/icons.cpp` converts their colours for a light one with the table the Godot editor uses for
  its light themes (`editor/themes/editor_color_map.cpp`).
- Those here: drawn for OUI Paint in the style of the Godot editor's (16 pixels, `#e0e0e0` for a dark interface,
  converted for a light one as those are), under Olagarro's license, for the tools Godot has no icon of.
