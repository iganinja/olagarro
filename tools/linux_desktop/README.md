# Desktop entries

What the Linux GUI package, oui-pack-gui, adds to the desktop's menu of applications: OUI Code and OUI Calc, each
with its entry, in /usr/share/applications, and its icon, in /usr/share/icons/hicolor/128x128/apps.

The icons are the ones the programs give their windows, `oui::text_icon` as each program's `main` calls it, drawn at
its 128 pixels a side: OUI Code's "OC" in white on Turbo C's blue, OUI Calc's "=" in blue on white. A change to a
program's window icon is made here too.
